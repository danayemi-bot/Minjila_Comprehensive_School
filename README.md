# Minjila Compre School

A command-line school management system built in Python. Practice project for
learning file I/O, SQLite, modular code organization, and testing.

## Features

- Student registration
- Login authentication
- Store school details
- SQLite persistence

## Setup

```bash
git clone https://github.com/danayemi_bot/Minjila_Compre_School.git
cd Minjila_Compre_School
python -m venv .venv
source .venv/bin/activate     # Windows: .venv\Scripts\activate
pip install -r requirements.txt
